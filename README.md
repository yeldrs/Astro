# Portfolio — Yassine El Idrissi

Personal portfolio for a UX / Product Designer. **100% static** site generated by Astro — no
server, no database, no runtime logic. Bilingual (EN at the root, FR under `/fr/`).

- **Live:** https://yassineelidrissi.com
- **Domain & email:** Hostinger (registrar + MX)
- **Hosting:** GitHub Pages — auto-deploy on every push to `main`
  (`.github/workflows/deploy.yml` + `public/CNAME`)

## Stack

| Layer | Tech |
|---|---|
| Framework | Astro 5 (`output: 'static'`, `build.format: 'file'`) |
| Content | Content Collections (`.md` frontmatter, Zod-validated) |
| Styles | Tailwind CSS 3, driven by design tokens (`src/styles/tokens.js`) |
| Types | TypeScript strict |

## Develop

```bash
npm install
npm run dev       # dev server (localhost:4321)
npm run build     # production build → dist/
npm run preview   # preview the build
```

## Docs

| File | Purpose |
|---|---|
| `CLAUDE.md` | Operating rules and layer map — read before changing anything |
| `ARCHITECTURE.md` | The *why*: routing, content mechanism, design-system chain, i18n |
| `BACKLOG.md` | Open items / what's next |
| `CHANGELOG.md` | Dated history (reference only) |
| `src/content/config.ts` | The content schema — the actual contract for a case study |

Adding a case study, editing the design system, and translating content each have a step-by-step
guide in `.claude/skills/`.
